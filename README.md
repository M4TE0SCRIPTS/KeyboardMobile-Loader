# Keyboard For Mobile

A lightweight Luau UI utility for Roblox touchscreen devices, featuring a 3D-styled on-screen keyboard, smooth animations, sound feedback, and a screen-bounded toggle button while keeping native controls intact.

## Usage

```lua
	loadstring(game:HttpGet("[https://raw.githubusercontent.com/M4TE0SCRIPTS/Keyboard-Main/refs/heads/main/KeyboardForMobile-Main](https://raw.githubusercontent.com/M4TE0SCRIPTS/Keyboard-Main/refs/heads/main/KeyboardForMobile-Main)"))()
end)
```
